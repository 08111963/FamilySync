```text
Dieta
[ menu a tendina ]
```

```text

```

Questa non è la UI richiesta.

Sostituisci i radio button con un vero selettore/dropdown compatibile con web ed Expo/mobile.

La schermata deve mostrare una sola riga, per esempio:

```text
Dieta

Mediterranea                         ▼
```

* Mediterranea
* Mediterranea senza glutine
* Mediterranea senza lattosio
* Vegetariana
* Vegetariana senza glutine
* Vegana
* Pescetariana
* Low carb
* Halal

Dopo la selezione deve rimanere visibile soltanto il profilo scelto.

Mantieni:

```ts
dietProfile
```

come valore canonico inviato al backend.

Non trasformare il dropdown in testo libero.

# 3. CARNE ROSSA

Attualmente il prompt contiene una regola equivalente a:

```text
ESATTAMENTE un pasto con carne rossa magra nella settimana
```

La richiesta funzionale è invece:

```text
almeno 1 pasto principale con carne rossa alla settimana
```

a pranzo oppure cena.

Non renderla dominante.

Usa una regola del tipo:

```text
includi almeno un pasto principale con carne rossa nella settimana,
preferibilmente uno, mantenendo la varietà delle fonti proteiche
```

Il checker deve considerare valido:

```text
red_meat >= 1
```

e non richiedere rigidamente:

```text
red_meat == 1
```
